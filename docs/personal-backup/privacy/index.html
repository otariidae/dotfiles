プライバシーポリシー

最終更新: 2026-10-11 · Personal Drive Backup

本アプリケーションは、所有者が自分の Google Drive 上のファイルを、自分が管理する端末およびストレージへバックアップするためにのみ使用します。

取得・利用するデータ

  • Google アカウントの OAuth 認可により、Drive 上のファイルおよびメタデータへアクセスします（設定したスコープの範囲）。
  • アクセスは所有者の端末上で動作するソフトウェアから行われ、バックアップ先は所有者の管理下（自宅のネットワークストレージ等）に限定されます。

第三者提供

取得した Google アカウントのデータや Drive の内容を、第三者へ販売・共有・公開することはありません。Google の API 利用に伴い、Google のプライバシーポリシーも適用されます。

保管

OAuth トークンおよびバックアップデータは、所有者の端末または所有者が管理するストレージに保存されます。第三者のアプリケーションサーバーには保管しません。
