利用規約

最終更新: 2026-10-11 · Personal Drive Backup

目的

本アプリケーションは、所有者が自分の Google Drive を個人的にバックアップするためのものです。一般公開のサービスや SaaS ではありません。

利用者

利用者はアプリケーション所有者本人に限ります。第三者への提供・再配布を目的としません。

免責

バックアップの完全性や可用性を保証しません。Google API・ネットワーク・端末・ストレージの障害によりデータが失われる可能性があります。重要なデータは複数の手段で保管してください。

Google の条項

Google Drive / Google API の利用にあたっては、Google の利用規約および API サービス利用規約にも従うものとします。

変更

本規約は必要に応じて更新することがあります。更新後の内容は本ページに掲示した時点から効力を持ちます。
